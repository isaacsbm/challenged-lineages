How to read the results

The two answers are compared row by row. A row only Dublin Core returns is marked extra: Dublin Core counted something that doesn’t answer the question. A row only the ccv query returns is marked missed by Dublin Core. Where Dublin Core alone gives the right answer, the page says so, because Dublin Core is the base of every record and ccv is meant to add only what it can’t express.
