How to read this vocabulary

The challenged collection is described in DCMI Metadata Terms first. These seven properties are added only where Dublin Core cannot express something: that a link between two works matters for censorship, how strong the evidence for that link is, and the who, why, where, and result of a challenge.

Each definition, domain, range, and comment is quoted from the project’s metadata analysis. Two additions make the vocabulary machine-readable. dcam:domainIncludes and dcam:rangeIncludes say what each property is used with, without the strict inferences of rdfs:domain and rdfs:range; DCMI Metadata Terms use the same pair. Every controlled value is also a SKOS concept with its own URI, such as ccv:outcome-banned, so data can point to a value instead of repeating a string. How these properties combine with Dublin Core in a record is set out in the application profile.

Properties

ccv:challengeLineage

Challenge Lineage

URI
https://isaacsbm.github.io/challenged-lineages/terms#challengeLineage
Definition
Links a challenged work to an earlier work from which it derives or to which it responds, where the later work's challenge concerns content, themes, or form carried over from the earlier work.
Domain
A creative work that has been formally challenged or suppressed.
Range
A creative work.
Comment
Differs from bf:derivativeOf and schema:isBasedOn by asserting a censorship relationship, not merely a creative one. The target need not itself be challenged (e.g., Beowulf for Grendel); when both are, the link records a shared history. Should be paired with ccv:influenceEvidence.
Used with
bf:Work, bf:Instance (dcam:domainIncludes)
Values
bf:Work (dcam:rangeIncludes)

ccv:influenceEvidence

Influence Evidence

URI
https://isaacsbm.github.io/challenged-lineages/terms#influenceEvidence
Definition
The basis on which a link between two works is established.
Range
One of: explicit reference; title or epigraph allusion; adaptation; retelling; parody; author-acknowledged; critical attribution; same author; genre lineage.
Comment
Records how strong the evidence for a ccv:challengeLineage link is, since influence claims vary widely in reliability. Values are listed roughly from most to least verifiable.
Used with
bf:Work, bf:Instance, rdf:Statement (dcam:domainIncludes)

ccv:challengeReason

Challenge Reason

URI
https://isaacsbm.github.io/challenged-lineages/terms#challengeReason
Definition
A stated reason given in a formal request to remove or restrict a work.
Range
A concept from a SKOS concept scheme. Starter values drawn from the rationales OIF reports most often: claimed obscenity for minors; LGBTQIA+ representation; race, racism, equity, and social justice; political or religious viewpoint; Palestinian representation; immigrant representation.
Comment
Records the reason as stated by the challenger, not as a finding. OIF notes that no school or public library book has ever been found by a court to meet the legal definition of obscenity for minors.
Used with
dcmitype:Event (dcam:domainIncludes)
Values
skos:Concept (dcam:rangeIncludes)

ccv:challengeInitiator

Challenge Initiator

URI
https://isaacsbm.github.io/challenged-lineages/terms#challengeInitiator
Definition
The category of person or body that filed a formal challenge.
Range
One of: government decision-maker; board member or administrator; pressure group; parent; library user; other.
Comment
Categories follow OIF's reporting, which shows government decision-makers and pressure groups behind nearly 92% of 2025 attempts. Use foaf:Agent to identify a specific person or organization where appropriate.

ccv:challengeVenue

Challenge Venue

URI
https://isaacsbm.github.io/challenged-lineages/terms#challengeVenue
Definition
The setting in which a challenge or other act of suppression took place.
Range
One of: school library; classroom curriculum; public library; academic library; government censor; court; customs or postal authority; publisher.
Comment
Lets one record compare library challenges with older and non-library forms of suppression found in this collection (We, Ulysses, The Wind Done Gone, the expurgated Fahrenheit 451).

ccv:challengeOutcome

Challenge Outcome

URI
https://isaacsbm.github.io/challenged-lineages/terms#challengeOutcome
Definition
The result of a formal request to remove or restrict a work.
Range
One of: retained; restricted; relocated; removed from curriculum; banned; expurgated; enjoined; pending; none recorded.
Comment
Distinguishes unsuccessful challenges from successful bans, mirroring OIF's distinction between books challenged, censored, and banned. "None recorded" lets a linked but unchallenged work (e.g., James) sit in the collection without implying a ban.
Used with
dcmitype:Event, bf:Work (dcam:domainIncludes)
Values
skos:Concept (dcam:rangeIncludes)
Value scheme
